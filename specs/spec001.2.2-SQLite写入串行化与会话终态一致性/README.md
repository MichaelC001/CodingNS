# spec001.2.2：SQLite 写入串行化与会话终态一致性

本 Spec 解决同一个 Host SQLite 文件被会话运行时、WebSocket 快照和终端日志 writer 同时写入时出现的锁等待、慢写和状态竞态。

## 文档入口

- [需求文档](./requirements.md)：要解决什么问题，以及什么结果算完成。
- [设计文档](./design.md)：写入顺序、事务边界、幂等提交和错误处理。
- [任务清单](./tasks.md)：按顺序执行的实现和验证任务。
- [验收记录](./docs/20260914-验收记录.md)：本轮实际运行的命令和结果。

## 范围

本 Spec 只改 Host 的 SQLite 写入协调、会话运行时事件持久化、终端日志索引提交和中断终态处理，不改变 provider 协议和前端交互协议。
