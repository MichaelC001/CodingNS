# spec001.2.2 验收记录

日期：2026-09-14

## 已完成内容

- 新增 `SqliteWriteQueue`，在 Host 进程内按 FIFO 串行执行高频写操作，busy 错误有限退避，失败后释放队列。
- 会话运行时写入（含 Claude 外部 hook）、工作区 discovery 批次和订阅快照写入接入共享队列。
- 终端 writer 使用请求 ID作为稳定分段 ID，重复提交不会重复创建 segment；文件尾部更新只向前推进。
- interrupt 遇到 `ACTIVE_RUN_NOT_FOUND` / `RUN_NOT_FOUND` 时按已结束处理并返回成功。

## 现象变化

- Host 内运行时事件不再各自维护 busy 重试，统一经过写入队列。
- 终端 writer 的锁竞争仍会按设计重试，但不会因提交重试生成重复索引或倒退偏移。
- 已结束运行收到 interrupt 不再映射为 `PROVIDER_IO_ERROR`。

## 剩余风险

终端 writer 仍是独立进程，和 Host 之间无法共享进程内队列；外部连接持有 SQLite 写锁时仍可能出现有限等待。若生产日志仍显示持续跨进程锁等待，下一步应单独立项把终端日志索引迁到独立数据库，本 Spec 不扩大范围。
