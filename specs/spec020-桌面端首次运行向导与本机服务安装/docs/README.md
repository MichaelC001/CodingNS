# 补充文档

这个目录放三类东西：

- **安装器命令行契约**：`host-install.mjs` 的动作、参数、输出格式和错误码。写 `install.sh` 和排查安装问题时先看这里。
- **验收记录**：每个阶段做完了，把真实的验证结果记下来，写清在什么机器上、跑了什么命令、看到什么结果。
- **界面与流程说明**：向导每一步长什么样、文案怎么组织，供后续改界面时对照。

约定：

1. 验收记录按 `日期-验收记录.md` 命名，一个阶段一份，不要把不同阶段的结论混在一起。
2. 记录里要写清楚机器的初始状态（有没有 Node、有没有装过 CodingNS），否则结论没法复现。
3. 失败和没验证的项要照实写，不要只写通过的部分。
