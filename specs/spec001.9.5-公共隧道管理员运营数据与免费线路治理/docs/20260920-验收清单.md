# 公共隧道管理员运营数据与免费线路验收清单

## 账号状态

- [ ] 新账号完成邮箱验证后才进入 `active`。
- [ ] `disabled` 账号不能登录，原有 token 立即失效。
- [ ] `disabled` 账号不能申请连接票据，也不会收到忘记密码邮件。
- [ ] 管理员启用账号后，原设备绑定可以继续使用。

## 设备状态

- [ ] 每个账号最多保留一台设备绑定，每台设备最多一个访问会话。
- [ ] 禁用设备会断开 Host 和客户端，设备记录、域名和历史流量保留。
- [ ] 凭据重置会递增凭据版本，旧 Host 凭据不能重新拿票。
- [ ] 管理员重新启用设备后，Host 使用新凭据版本重新登记。

## 在线和访问口径

- [ ] Host 最近心跳不超过 30 秒时显示 Host 在线。
- [ ] 只有 DataChannel 建立成功的客户端才显示正在访问。
- [ ] 真实 candidate pair 不含 relay 时显示直连，任一端为 relay 时显示中继，没有成功上报时显示未知。
- [ ] 信令连接、SDP 协商、ICE 等待不会被计为访问会话。

## 流量

- [ ] 默认免费线路显示 `500 KB/s`，内部限速值为 `512000 bytes/s`。
- [ ] 上行和下行共享总带宽额度。
- [ ] 免费线路不因累计用量耗尽而拒绝连接。
- [ ] 实时速率使用最近 60 秒窗口，历史查询支持今日、本月和自定义日期。
- [ ] 原始会话事件保留 30 天，账号和设备日汇总永久保留。

## 管理后台

- [ ] 总览每 15 秒刷新，实时来源不可用时明确显示不可用。
- [ ] 管理员可以查看 Host 在线、正在访问、直连/中继、实时速率和累计用量。
- [ ] 账号启用、禁用、密码重置邮件，设备启用、禁用、凭据重置和限速修改都要求填写原因。
- [ ] 每次状态变更都有审计记录，查询操作不写审计。
- [ ] 页面没有付费会员、自动续费或月订阅入口。
