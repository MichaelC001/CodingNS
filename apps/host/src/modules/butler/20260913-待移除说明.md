# Butler 待移除说明

Butler 已停止对外提供功能，当前状态是“代码保留、运行时停用”。

## 已停用的入口

- `/api/butler/*` 路由不再注册。
- 外部渠道管理、轮询、投递和 webhook 入口不再注册或接收消息。
- Butler 专用的助手能力调用被拒绝。
- 巡视、跟进、控制定时器三个周期调度器不再启动。
- Butler 跟进会话的终态监听不再注册。
- Butler 运行时不再挂入历史会话的活动状态解析和会话运行时路由。
- 事务助手会话快照服务不再实例化，因此不会注册后台任务或触发会话同步。

## 暂时保留的代码

`apps/host/src/modules/butler/`、相关 repository、数据库表和前端 `features/butler/` 暂不删除，供后续一次性清理和历史数据迁移使用。

所有新增 Butler 代码都应视为禁止新增；删除前不得重新打开 `butler-feature-status.ts` 的开关。
